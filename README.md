# Math Game built w vanilla JS

A simple browser-based math game built to practice basic arithmetic and frontend development.

The game generates math problems for the player to solve and provides an interactive way to practice calculations.

## Features

- Randomly generated math problems
- Interactive gameplay
- Score tracking
- Simple, responsive interface
- Runs entirely in the browser

## Tech

Built with **HTML, CSS and JavaScript**.
